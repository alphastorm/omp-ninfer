What is measured

  • RTX 5090 (qwen38-5090-v0.13.0, DFlash2 draft window 7, BF16 KV, runtime carried from v0.13.0, model 81f924d4): exact 130,048-token retrieval in 56.99 s cold; 2,048-token decode at 179.86 tok/s server-side (176.27 tok/s wall).
  • RTX 4090 native Windows 11 (v0.7.0-qwen38-4090-beta.2, MTP3, INT8 KV, model 81f924d4): exact 130,048-token retrieval in 85.71 s; C1 decode at 150.94 tok/s (87.59% MTP acceptance, 2,190.89 tok/s prefill).
  • RTX 3090 native Windows 11 (v0.7.0-qwen38-3090-beta.2, MTP3, INT8 KV, 300 W serving cap, model 81f924d4): exact 130,048-token retrieval in 208.78 s; C1 decode at 84.06 tok/s (92.96% MTP acceptance, 921.63 tok/s prefill).

Historical v0.4.0 restart receipt (2026-08-30, one RTX 5090, not a current-release timing or restart speed-up ratio): 109,589 retained tokens served after a Docker restart in 24.8 s end-to-end including first-touch restore of a 7.95 GB checkpoint, with a 56.6 s model reload measured separately and 0.778 s server TTFT after restoration. Checkpoints already leave the machine

Checkpoints restore after a server restart on all three qualified lanes, and scripts/checkpoint_sync.py exports and imports verified checkpoint generations across local storage and off-machine replicas. Network shares are replica storage, never the live checkpoint root.

Restore requires the same runtime binary, model artifact, serving profile, and session credentials; checkpoint saves remain best effort under live traffic, and universal warm reuse is not promised. Oh My Pi’s transcript remains the source of truth, so losing retained state degrades to a transcript replay rather than cloud fallback. Scope, usage, and receipts.

Use it when

  • You use Oh My Pi (18.12.6 in v0.13.1) and own an eligible RTX 5090, RTX 4090, or RTX 3090 setup matching the exact release profile.
  • Qwen3.8 27B is the model you want, running privately on hardware you own.
  • Coding sessions are long-lived, and explicit continuation across inference-server restarts matters more than model catalog breadth.

Use something else when

You want a broad model catalog (Ollama), a desktop GUI (LM Studio), maximum portability (llama.cpp), or multi-user serving (vLLM). The comparison is candid about this — the narrow target is what makes the recommendation credible.

How it fits together

Oh My Pi (coding-agent client) → OMP NInfer (qualified appliance and release layer) → NInfer (inference engine) → Qwen3.8 27B (served model: 20.4 GB 81f924d4 across all three lanes). Loopback-only, bearer-authenticated, fail-closed instead of cloud fallback, every byte hash-pinned. Full detail: canonical facts.

Oh My Pi owns the conversation transcript, tools, coding workflow, and subagents. Neroued’s NInfer and its GPU ports supply the single-GPU engine; this project’s runtime adds explicit OpenAI Responses continuation state (previous_response_id) and durable local NVMe checkpoints. Ordinary in-process prefix caching already reuses matching input in a live server and is conceded as prior art; the claim here is transactional continuation across restarts.
