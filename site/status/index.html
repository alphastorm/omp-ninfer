Native two-GPU sequential topology and rollback

  • One native lane at a time on port 18082: Both native Windows lanes install on one two-GPU Windows 11 host (RTX 4090 at index 0, RTX 3090 at index 1), each bound to its own GPU UUID and PCI address. Only one native lane runs at a time on authenticated loopback port 127.0.0.1:18082. This is not multi-GPU inference and not concurrent native serving.
  • First-of-lineage native rollback: Both rebased native Windows lanes (v0.7.0-qwen38-4090-beta.2 and v0.7.0-qwen38-3090-beta.2) are the first release of their 64d10fbf / model v3 lineage on the two-GPU host and have no supported rollback target (rollback: not_applicable, zero directions); the historical RTX 3090 v0.6.2-beta.1 rollback result does not transfer across the model and runtime rebase, and prior native release roots stay preserved separately for historical recovery.

Client scope and operating boundaries

  • Stock Oh My Pi 18.12.6: Unmodified upstream release assets (omp-darwin-arm64 cfbb5e38, omp-windows-x64.exe 73d73c11, omp-linux-x64 85d9daf3) pinned in client-components.json. Stock OMP has no omp appliance commands; model fragments set per-model compat.statefulResponses: true, PI_OPENAI_STATEFUL must be absent, and examples/manual-tunnel/fail-closed.yml limits in-flight requests per provider (2 on RTX 5090, 1 per native lane).
  • macOS preview: The macOS arm64 client reaches the Windows RTX 5090 container over a manual authenticated SSH local forward (127.0.0.1:18089); it remains preview without a managed client installer or appliance lifecycle wrapper.
  • Linux under WSL2: Live Linux-client qualification ran on Ubuntu under WSL2 against the local RTX 5090 container, not on a separately qualified non-WSL Linux OS.
  • Durability and checkpoints: Checkpoints restore after a server restart on all three lanes within the same runtime binary, model artifact, serving profile, and session credentials. Saves remain best effort under live traffic (a crash or expired graceful wait can lose unsaved work), and universal warm reuse is not promised. Checkpoint transport and NAS replication.
