The authority now uses the client’s existing durable-checkpoint capability rather than the rejected process-restart-continuation name; this vocabulary fix adds no runtime behavior.

Known caveats

  • One active request per lane (max concurrency 1); not a serving farm.
  • Carried v0.7.2 evidence: both target 126K-token RTX 5090 sessions resumed in 5.96 s and 23.57 s. The combined probe process also reported three unsaved predecessor sessions at shutdown, and a separate control lost warm reuse on 2 of 8 continuations/forks. This is not universal durability or warm reuse; automatic checkpoints remain best effort. Exact-source evidence and limits.
  • Host/NAS replicas are supported; restore requires the same binary, artifact, profile, and session credentials. Transport is not cross-GPU migration or automatic failover. Evidence and limits.
  • Use the exact Oh My Pi client pinned by the release manifest; do not run omp update over a lane install.
